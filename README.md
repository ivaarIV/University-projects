## About

This repository organizes Rust course exercises and projects, supports structured code review, and records contributions through GitHub's Pull Request workflow.

## Repository visibility

The repository is intended to remain **private during the course term**. It may become public after the term only when the instructor/course staff has approved publication and all submissions have been checked for privacy, academic-integrity, and licensing concerns. Do not assume that every student submission is automatically eligible for public release.

## Contribution workflow

1. Read [CONTRIBUTING.md](CONTRIBUTING.md).
2. Create a branch or fork according to the course staff's workflow.
3. Add your exercise or project to the appropriate folder.
4. Open a Pull Request against `main`.
5. Respond to review feedback. Only authorized maintainers should merge submissions.

## Academic integrity and privacy

Submit only work you are authorized to share. Do not include credentials, API keys, student IDs, grades, private information, hidden tests, confidential grading rubrics, or official solutions that the instructor has not approved for release.

## Responsibilities and attribution

The Head TA role and responsibilities listed here should reflect the actual course arrangement. Add the official course page or instructor confirmation if available. Repository activity can document contributions, but it does not independently certify an appointment.

## License and reuse

No license has been selected for student submissions. Unless the author or course staff has granted permission, do not assume code in this repository may be reused outside the course. Confirm publication and licensing rights before making the repository public.
